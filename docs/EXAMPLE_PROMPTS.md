# Example Prompts

## Purpose

This document defines starter prompts that help users understand what to paste into Prompt Architect Studio.

Examples should be realistic, approachable, and tied to the target personas.

## Example Guidelines

Good examples are:

- Specific enough to produce a useful result.
- Short enough to scan.
- Common enough that users recognize the use case.
- Varied across personas.
- Friendly to people who do not think in prompt-engineering terms.

Avoid examples that are:

- Gimmicky.
- Too broad.
- Too technical for the core audience.
- Narrowly B2B unless the section calls for it.
- Dependent on private data.

## Everyday AI User Examples

### Research

### Email

## Default Example Rotation

The MVP should rotate between 3 to 5 examples.

Recommended first set:

1. Write a friendly email announcing new weekend hours for my neighborhood bakery.
2. Help me turn scattered notes into a simple weekly plan I can actually follow.
3. Create a prompt for comparing three options before I buy new software for my shop.
4. Turn messy client notes into a clear marketing action plan.
5. Create a prompt for converting raw meeting notes into decisions, owners, risks, and next steps.
