# Reference Analysis

## Reference Site

Salient Business 3  
https://themenectar.com/salient/business-3/

## Why This Reference Is Useful

This reference is useful for page rhythm, confidence, section sequencing, and visual polish.

It should not be copied literally. Prompt Architect Studio is not a coworking, real estate, or image-heavy business site. The useful lesson is how the page creates momentum:

1. Strong hero promise.
2. Minimal navigation.
3. Clear CTA.
4. Visual confidence.
5. Alternating content sections.
6. Scannable feature blocks.
7. Social proof or trust context.
8. Final CTA.

## What To Borrow

### 1. Confident Hero

The reference uses a clear, emotionally direct hero headline.

For Prompt Architect Studio:

> Turn messy ideas into model-ready prompts.

The hero should quickly answer:

- What is this?
- Why does it matter?
- What should I do next?

### 2. Minimal Navigation

The reference keeps navigation light.

For Prompt Architect Studio:

- Product name/logo.
- How it works.
- Frameworks.
- Start.

Avoid full dashboard navigation in the MVP.

### 3. Section Rhythm

The reference has clear section changes instead of one long flat page.

For Prompt Architect Studio:

1. Hero.
2. Studio workspace.
3. How it works.
4. Frameworks.
5. Why prompt architecture matters.
6. Use cases.
7. Trust/privacy.
8. Final CTA.

### 4. Visual Confidence

The reference feels like a complete product/company, not a form dropped on a blank page.

For Prompt Architect Studio:

- Use clean visual hierarchy.
- Make the output block feel valuable.
- Use purposeful cards and sections.
- Give the app a distinct visual identity.

### 5. CTA Clarity

The reference uses clear action prompts.

For Prompt Architect Studio:

- Primary CTA: “Start Architecting”
- Secondary CTA: “See How It Works”
- Output CTA: “Copy Prompt”

## What Not To Borrow

Avoid:

- Coworking/property visual language.
- Random photo grids.
- Decorative images that do not explain the product.
- Long generic marketing sections.
- Template filler copy.
- Overly large hero that hides the tool.

## Translation For This Product

The reference site sells a place. Prompt Architect Studio sells a workflow.

So our visuals should show:

- Rough input becoming structured output.
- Framework choices.
- Model calibration.
- Prompt architecture rules.
- Work use cases.

If a visual element does not explain or reinforce that workflow, it should not be included.

## Design Takeaway

Use the reference for flow and polish, not subject matter.

The final app should feel like:

> A polished SaaS landing page wrapped around an immediately usable AI workbench.
